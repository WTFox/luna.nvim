# Luna Zed theme

Two variants: blurred and opaque, respecting the original Neovim theme as much as possible. Differences in highlighting are most likely due to differing Treesitter queries.

## Installation

The colorscheme will eventually be in the official Zed extensions catalogue. [Extension repository for the theme](https://github.com/miropls/zed-luna)

Until then, or if you'd prefer to install the theme without using the extension:

1. Copy the wanted theme files `luna.json` or `luna-blur.json` to `~/.config/zed/themes`
2. Open the theme selector with
   a) the command palette (cmd-shift-p / ctrl-shift-p)
   b) with the default keybind (cmd-k cmd-t / ctrl-k ctrl-t)
3. Search or select Luna or Luna (Blur) from the menu and hit enter
