# WezTerm luna Theme

1. Create a `colors` directory in your WezTerm config directory if it doesn't already exist (usually `$HOME/.config/wezterm/colors`).
2. Copy `luna.toml` there.
3. In `wezterm.lua`, set `config.color_scheme = "luna"`.
4. Reload your WezTerm config (`CTRL+SHIFT+R` by default) to apply the change.
