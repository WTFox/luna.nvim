# Ghostty luna Theme

1. Navigate to your Ghostty config directory (usually `$HOME/.config/ghostty`).
2. Inside it, create a `themes` directory if it doesn't already exist.
3. Save `luna` in that directory.
4. In your Ghostty config (usually `$HOME/.config/ghostty/config`), add:
   ```
   theme = luna
   ```
5. Reload your Ghostty config to apply the change.
