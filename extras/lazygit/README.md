# Lazygit luna Theme

1. Navigate to your lazygit config directory (usually `$HOME/.config/lazygit`).
2. Copy `luna.yml` there, or merge its contents into your existing `config.yml`.
3. If you don't already use [difftastic](https://github.com/Wilfred/difftastic) for diffs, either install it or remove the `git.diffRenderers` block.
4. Restart lazygit to apply the change.
