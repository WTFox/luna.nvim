# fzf luna Theme

1. Copy `luna.sh` to a location of your choice (e.g. `$HOME/.config/fzf/luna.sh`).
2. Source it from your shell config (`.zshrc`, `.bashrc`, etc.): `source $HOME/.config/fzf/luna.sh`.
3. Alternatively, paste the `export FZF_DEFAULT_OPTS` block directly into your shell config. Note that it will overwrite any `FZF_DEFAULT_OPTS` you've already set.
4. Restart your shell, or run `exec $SHELL`, to apply the change.
